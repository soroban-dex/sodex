# Security Policy

Sodex is a testing toolkit and does not certify the security
or completeness of an indexer.

Please do not publish credentials, private keys, access tokens,
or sensitive infrastructure details in issues or test fixtures.

For potentially sensitive security reports, contact the repository
maintainers privately through a verified GitHub security reporting
channel if one is enabled.

Include:
- A concise description of the issue
- Affected version or commit
- Reproduction steps that do not expose secrets
- Expected and observed behavior

Do not test against systems you do not own or have permission to test.
